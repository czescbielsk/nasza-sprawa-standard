# BCP 14 — konwencja wymagań normatywnych

Propozycja NSS-001/NSS-005. Źródła: https://www.rfc-editor.org/rfc/rfc2119 i https://www.rfc-editor.org/rfc/rfc8174. RFC 8174 doprecyzowuje znaczenie słów kluczowych pisanych wielkimi literami. Proponujemy własną polską konwencję, nie twierdząc, że polskie tłumaczenia są oficjalnymi słowami kluczowymi BCP 14.

| NSS | Odpowiednik angielski | Znaczenie |
| --- | --- | --- |
| MUSI | MUST | Obowiązek zgodności |
| NIE MOŻE | MUST NOT | Zakaz |
| POWINIEN | SHOULD | Zalecenie, odstępstwo wymaga uzasadnienia |
| NIE POWINIEN | SHOULD NOT | Zalecenie unikania, odstępstwo wymaga uzasadnienia |
| MOŻE | MAY | Dopuszczalna opcja |

Konwencja dotyczy wyłącznie jawnie normatywnych fragmentów. Każde wymaganie otrzymuje trwały identyfikator, zakres profilu, podmiot i warunek sprawdzenia. Przykłady i uzasadnienia są informacyjne. Nie narzucamy technicznej realizacji.

Przykład kandydata NSS-CORE-REQ-001: Organizacja prowadząca sprawę MUSI zachować identyfikatory zgłoszeń po ich powiązaniu ze wspólną potrzebą. Test: CS001-T01. Przykład nie jest jeszcze zatwierdzonym wymaganiem.

Przed przyjęciem: sprawdzić warunki ponownego wykorzystania RFC; stosować własne opisy, nie kopiować tekstu. Uzgodnić słownik i identyfikatory w NSS-005.
