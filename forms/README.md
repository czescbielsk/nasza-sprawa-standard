# Zestaw analogowy — wydrukuj i przetestuj

Formularze są szkicami do pilotażu. Można je przepisać na kartce, skopiować lub wydrukować. Nie wymagają systemu informatycznego.

1. [Karta zgłoszenia](karta-zgloszenia.md) — punkt wejścia.
2. [Rejestr spraw](rejestr-spraw.md) — publiczny w wersji bez danych osobowych lub wewnętrzny.
3. [Karta decyzji](karta-decyzji.md) — kto zdecydował, w jakim zakresie i dlaczego.
4. [Dziennik zdarzeń](dziennik-zdarzen.md) — chronologia sprawy na papierze.
5. [Karta działania i rezultatu](karta-dzialania-i-rezultatu.md) — wykonanie, efekt i weryfikacja.

**Zasady bezpieczeństwa:** nie publikuj danych kontaktowych ani danych dotyczących zdrowia lub innych wrażliwych sytuacji. W razie zagrożenia życia lub bezpieczeństwa skieruj osobę do właściwych służb. Nie wykorzystuj formularzy do zastępowania oficjalnych kanałów prawnych, jeśli sprawa ich wymaga.
