# NSS-CS-032 — Dzieci proponują miejsce do zabawy
Hipotetyczny v0.1. Dzieci przedstawiają pomysły na plac zabaw na spotkaniu w szkole. Opinie zapisane bez zbędnych danych osobowych, przedstawione właściwemu decydentowi. Dzieci otrzymują zrozumiałe uzasadnienie, także odmowy. Nie podejmują zobowiązań inwestycyjnych.
Testy niewykonane: T01 głos dzieci zachowany; T02 brak publicznych danych; T03 mandat odrębny od opinii; T04 zrozumiała odpowiedź; T05 brak automatycznego odrzucenia z powodu wieku.
