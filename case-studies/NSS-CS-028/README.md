# NSS-CS-028 — Kontrybucja spoza miejscowości
Hipotetyczny wariant CS027, v0.1. Parafia publikuje zapotrzebowanie na materiały; przedsiębiorca z innej miejscowości otrzymuje informację przez własny portal i oferuje transport. Obie strony uzgadniają warunki; parafia potwierdza przyjęcie, aktualizuje zapotrzebowanie. Brak wspólnego konta nie blokuje współpracy.
Testy niewykonane: T01 zachowanie wystawcy i ID; T02 oferta nie jest zobowiązaniem; T03 powtórna wiadomość nie dubluje wkładu; T04 wycofanie oferty aktualizuje plan; T05 telefoniczna odpowiedź możliwa.
