# Studia przypadku

Studia przypadku służą projektowaniu standardu, weryfikacji proceduralnej, testom implementacji i prezentacji dla mieszkańców, administracji i partnerów. Każdy przypadek ma trwały identyfikator NSS-CS-NNN, wersję i klasyfikację: hipotetyczny, rzeczywisty udokumentowany lub zweryfikowany w pilotażu. Wyniki oczekiwane nie są wynikami rzeczywistymi. Dane osobowe i informacje niepubliczne nie trafiają do publicznego repozytorium.
