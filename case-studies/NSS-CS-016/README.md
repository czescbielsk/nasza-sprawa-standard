# NSS-CS-016 — Sprzeczne informacje o lokalnym popycie

Wersja 0.1, hipotetyczny szkic, testy niewykonane. Dwie ankiety dotyczące kawiarni dają sprzeczne wyniki; część odpowiedzi może pochodzić od tych samych osób. Inwestor, mieszkańcy i koordynator rozróżniają źródła, okresy i metody, nie sumują bez uzasadnienia. Nowy pilotaż dostarcza danych o faktycznych zakupach. Korygują ocenę popytu, zachowując ślad korekty zgodnie z retencją. Nie publikują danych klientów.

CS016-T01: sprzeczne wyniki zachowują odrębne źródła i niepewność. CS016-T02: korekta wskazuje podstawę, nie fałszuje historii. CS016-T03: informacja telefoniczna jest dostępna na równych zasadach. CS016-T04: deklaracje zainteresowania nie stają się zamówieniami.

Prezentacja: przedsiębiorca może ocenić jakość dowodów przed inwestycją. Brak rzeczywistych wyników. Powiązania NSS-001, 004, 008, 010, 014.
