# NSS-CS-031 — Senior bez internetu współtworzy inicjatywę
Hipotetyczny v0.1. Senior telefonicznie oferuje materiały do żywej szopki. Koordynator odczytuje zapis, uzgadnia ilość i termin, przekazuje odpowiedź telefonicznie. Nie zakłada konta bez zgody.
Testy niewykonane: T01 brak konta nie blokuje oferty; T02 autor i zapisujący rozróżnieni; T03 potwierdzenie zobowiązania; T04 odpowiedź offline; T05 prywatność kontaktu.
