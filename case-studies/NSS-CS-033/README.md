# NSS-CS-033 — Dostępne wieczorki literackie
Hipotetyczny v0.1. Uczestnicy wskazują potrzebę dostępnego wejścia, alternatywnego formatu informacji i wsparcia komunikacyjnego. Biblioteka uzgadnia dostosowania, sprawdza wykonalność i informuje o ograniczeniach. Nie wymaga diagnozy do zgłoszenia potrzeby.
Testy niewykonane: T01 dostępny kanał; T02 minimalizacja danych; T03 dostosowania w planie; T04 informacja o ograniczeniach; T05 ocena dostępności przez uczestników.
