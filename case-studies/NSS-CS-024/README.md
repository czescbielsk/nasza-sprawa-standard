# NSS-CS-024 — Wspólny zasób, konkurujące inicjatywy

Hipotetyczny szkic v0.1, testy niewykonane. Grupy mentoringowa i taneczna chcą korzystać z tej samej sali. Właściciel określa warunki, grupy uzgadniają terminy i odpowiedzialność. Gdy brak porozumienia, dokumentują przeszkody i alternatywy. Nowa sala umożliwia powrót do odroczonej propozycji.

CS024-T01: dostępność zasobu nie oznacza rezerwacji. T02: decyzje grup nie wiążą właściciela. T03: konflikt i kryteria rozstrzygnięcia zapisane. T04: nowy zasób wywołuje ponowną ocenę, nie automatyczne zatwierdzenie.

Prezentacja: niezależne inicjatywy mogą współdzielić zasoby bez centralnego zarządzania. Brak rzeczywistych wyników.
