# NSS-CS-026 — Biblioteka inicjuje współpracę

Hipotetyczny szkic v0.1, testy niewykonane. Biblioteka oferuje salę i zgłasza potrzebę prowadzących spotkania literackie. Lokalni autorzy, szkoła i przedsiębiorca oferują czas, promocję lub wsparcie. Każdy niezależnie potwierdza własne zobowiązania. Biblioteka prowadzi własną tablicę, partnerzy własne działania. Wycofanie sponsora nie oznacza automatycznego zakończenia wszystkich spraw.

CS026-T01: instytucja może inicjować potrzebę i ofertę. T02: oferta nie jest zobowiązaniem. T03: niezależne tablice i powiązane ID. T04: wycofanie partnera i ponowna ocena planu. T05: udział offline i ochrona danych.
