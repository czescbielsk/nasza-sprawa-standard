# NSS-CS-029 — Nieaktualna oferta w innym portalu
Hipotetyczny v0.1. Biblioteka publikuje dostępność sali, partner kopiuje ogłoszenie. Sala przestaje być dostępna, aktualizacja dociera z opóźnieniem. Partner oznacza nieaktualność i sprawdza warunki u wystawcy przed uzgodnieniem. Nie zakłada rezerwacji.
Testy niewykonane: T01 wersja i źródło; T02 wycofanie; T03 opóźniona aktualizacja nie nadpisuje nowszej; T04 brak automatycznej rezerwacji; T05 korekta bez ujawnienia danych chronionych.
