# NSS-CS-034 — Pośrednik zmienia sens zgłoszenia
Hipotetyczny v0.1. Mieszkaniec zgłasza potrzebę wieczornych kursów autobusu; pośrednik zapisuje ją jako żądanie nowej linii. Mieszkaniec otrzymuje kopię, zgłasza korektę innym kanałem. Organizacja zachowuje pochodzenie i koryguje zapis, informuje odbiorców w zakresie uprawnień.
Testy niewykonane: T01 autor odrębny od pośrednika; T02 dostępna korekta; T03 brak domniemanego mandatu; T04 historia korekt z retencją; T05 alternatywny kanał skargi.
