# NSS-CS-017 — Konflikt interesów przy wyborze dostawcy

Wersja 0.1, hipotetyczny szkic, testy niewykonane. Grupa organizująca odpłatne warsztaty rozważa wynajem lokalu od członka grupy. Ujawnia istotne powiązanie, określa mandat i kryteria, porównuje dostępne oferty oraz ustala wyłączenie z decyzji, jeśli wymagają tego reguły lub prawo. Przy środkach publicznych właściwe procedury mają pierwszeństwo. Brak zgody właściciela nie tworzy zobowiązania.

CS017-T01: konflikt i sposób obsługi są odnotowane. CS017-T02: rekomendacja nie jest umową. CS017-T03: decyzja wskazuje kryteria, mandat i uzasadnienie. CS017-T04: nowe informacje można zgłosić również offline.

Prezentacja: przejrzysty wybór partnera chroni zaufanie bez wykluczania lokalnych firm. Brak rzeczywistych wyników. Powiązania NSS-007, 008, 010, 014.
