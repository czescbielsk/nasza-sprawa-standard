# Testy akceptacyjne — kandydaci

Wersja standardu: roboczy PR #1. Status wszystkich testów: niewykonane. Mapowanie na trwałe identyfikatory wymagań po NSS-005.

| ID | Warunek i czynność | Oczekiwany wynik / dowód |
| --- | --- | --- |
| CS001-T01 | Dwa zgłoszenia tej samej potrzeby | Zachowane oba ID i powiązania ZG/PO/SP w rejestrze |
| CS001-T02 | Zgłoszenie telefoniczne bez konta | Karta z kanałem, pośrednikiem i sposobem odpowiedzi; kontakt niepubliczny |
| CS001-T03 | Wysłanie informacji bez odpowiedzi | Dziennik nie wykazuje przyjęcia zobowiązania zarządcy |
| CS001-T04 | Jedno działanie wykonane, drugie przerwane | Oddzielne stany i uzasadnienie; kandydat wymagający rozszerzenia rdzenia |
| CS001-T05 | Praca wykonana, problem nadal istnieje | Wynik potrzeby NIE lub CZĘŚCIOWO, niezależnie od zamknięcia sprawy |
| CS001-T06 | Nowy dowód po zamknięciu | Ponowne otwarcie z uzasadnieniem i zachowaną historią |
| CS001-T07 | Publikacja rejestru | Brak danych kontaktowych i nieuprawnionych danych osobowych |
| CS001-T08 | Odpowiedź osobie bez internetu | Dowód przekazania informacji uzgodnionym kanałem lub zapis nieudanej próby |

Wykonać na papierze i w przyszłych implementacjach cyfrowych. Zapisać wersję, datę, dowody, wynik i odstępstwa. Nie deklarować zaliczenia bez wykonania.
