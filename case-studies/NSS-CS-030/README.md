# NSS-CS-030 — Współpraca bez wspólnej aplikacji
Hipotetyczny v0.1. Biblioteka prowadzi papierowy rejestr, stowarzyszenie własną aplikację, portal regionalny publikuje zaproszenie do warsztatów. Koordynator ręcznie przekazuje uzgodnione informacje i potwierdzenia, zachowując identyfikatory i mandat. Każda organizacja ma własne stany spraw.
Testy niewykonane: T01 ręczna wymiana; T02 odrębne identyfikatory; T03 odbiór nie jest akceptacją; T04 niezależne statusy; T05 minimalizacja danych.
