# Kandydaci na testy — niewykonane

| ID | Oczekiwany wynik |
|---|---|
| CS027-T01 | Instytucja inicjuje projekt i publikuje potrzeby bez wcześniejszego zgłoszenia mieszkańca. |
| CS027-T02 | Oferta nie jest zobowiązaniem; obie strony potwierdzają warunki. |
| CS027-T03 | Kilka ofert częściowo pokrywa potrzebę bez podwójnego liczenia. |
| CS027-T04 | Darowizna, użyczenie i odpłatna usługa mają odrębne warunki. |
| CS027-T05 | Wycofanie lub niedostarczenie aktualizuje dostępność i plan. |
| CS027-T06 | Oferta zwierzęcia nie zostaje przyjęta bez oceny opieki, dobrostanu i bezpieczeństwa. |
| CS027-T07 | Zgłoszenie telefoniczne lub papierowe jest obsługiwane bez konta. |
| CS027-T08 | Publiczna tablica nie ujawnia zbędnych danych osobowych. |
| CS027-T09 | Zwrot użyczonych zasobów i rozliczenie zobowiązań są odrębne od zakończenia wydarzenia. |
| CS027-T10 | Ocena rezultatu i wnioski są zapisane również przy anulowaniu. |
