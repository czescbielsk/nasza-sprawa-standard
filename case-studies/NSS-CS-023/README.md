# NSS-CS-023 — Przeciążenie aktywnych mieszkańców

Hipotetyczny szkic v0.1, testy niewykonane. Grupa organizuje bazarek, warsztaty i festyn, ale te same osoby przyjęły zbyt wiele zadań. Ujawnia blokady, uzgadnia lokalny limit pracy w toku, odracza część działań z uzasadnieniem i szuka nowych chętnych. Nie przydziela pracy bez zgody.

CS023-T01: widoczna blokada i odpowiedzialność. T02: limit dotyczy pracy, nie wartości człowieka. T03: odroczenie nie usuwa potrzeby. T04: nowe zasoby umożliwiają ponowną ocenę.

Prezentacja: mniej rozpoczętych działań może oznaczać więcej ukończonych. Brak rzeczywistych wyników.
