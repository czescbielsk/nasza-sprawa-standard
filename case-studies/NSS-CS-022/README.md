# NSS-CS-022 — Godzina miesięcznie dla społeczności

Hipotetyczny szkic v0.1, testy niewykonane. Mieszkaniec oferuje godzinę miesięcznie na mentoring. Grupa proponuje małe samodzielne zadanie z jasnym rezultatem; uczestnik potwierdza zakres, bez obowiązku dalszego udziału. Alternatywa: odmawia zadania lub wycofuje się, grupa uzgadnia przekazanie.

CS022-T01: oferta czasu nie jest zobowiązaniem. T02: zadanie mieści się w uzgodnionym zakresie. T03: wycofanie i przekazanie zapisane bez publicznego rankingu osoby. T04: uczestnictwo offline możliwe.

Prezentacja: nawet niewielki wkład może być użyteczny. Brak rzeczywistych wyników.
